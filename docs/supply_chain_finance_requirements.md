# 供应链金融一期需求文档

## 背景与目标

船供采购在确认下单后会形成明确的采购金额。供应链金融模块用于把采购单金额拆分为企业自有资金预付和平台/金融机构贷款两部分，帮助买方在大额采购中管理现金流、融资申请、放款和还款节点。

一期目标是新增“供应链金融”菜单和静态业务样式，用于确认产品口径和页面信息结构；本期不接真实支付、授信审批、放款、还款或征信接口。

## 一期范围

1. 新增菜单：供应链金融。
2. 新增静态页面：展示下单后金额、预付金额、融资贷款金额、融资比例、申请状态和还款节点。
3. 金额拆分口径：采购单总金额 = 预付金额 + 供应链金融贷款金额。例如采购单 100 万，预付 20 万，剩余 80 万走金融贷款。
4. 页面只展示样式和业务字段，不改变现有采购、下单、供采和结算流程。

## 角色与使用场景

- 买方/船代：查看可融资采购单，选择预付比例，提交融资申请。
- 平台运营：查看融资申请状态、风险等级和资料完整度。
- 金融机构：后续可接入授信、审批、放款和还款确认。
- 供货商：后续可查看与自身订单相关的回款状态，本期不展示。

## 核心概念

- 采购单金额：采购单确认后固化的应付总额。
- 预付金额：买方先行支付或锁定的自有资金。
- 融资金额：采购单金额扣除预付金额后的贷款申请金额。
- 预付比例：预付金额 / 采购单金额。
- 贷款期限：从放款到约定还款日的周期。
- 年化利率：融资方案展示口径，本期为静态样例。
- 风险等级：基于订单、企业资料、历史履约和授信情况的展示字段，本期为静态样例。

## 页面结构

### 1. 总览指标

- 可融资采购金额
- 已锁定预付金额
- 申请中融资金额
- 待还金额

### 2. 金额拆分看板

展示采购单 100 万的示例拆分：

- 预付金额：20 万
- 金融贷款：80 万
- 预付比例：20%
- 融资比例：80%

### 3. 可融资采购单列表

字段建议：

- 采购单号
- 船舶
- 供货商
- 采购金额
- 预付金额
- 融资金额
- 预付比例
- 贷款期限
- 年化利率
- 状态

状态建议：

- 待申请
- 预付待确认
- 审核中
- 已放款
- 还款中
- 已结清
- 已驳回
- 逾期

### 4. 还款与风控节点

展示关键时间线：

- 采购单确认
- 预付锁定
- 融资审核
- 放款至供货商
- 到期还款

## 后续接口建议

后续真实化时可补充以下接口，当前一期不实现：

- `GET /api/supply-chain-finance/orders`：可融资采购单列表。
- `GET /api/supply-chain-finance/applications/{id}`：融资申请详情。
- `POST /api/supply-chain-finance/applications`：提交融资申请。
- `PUT /api/supply-chain-finance/applications/{id}/prepayment`：更新预付金额或比例。
- `GET /api/supply-chain-finance/repayments`：还款计划。

## 验收点

1. 左侧菜单出现“供应链金融”，点击进入静态页面。
2. 页面能表达“下单后产生金额，可拆分为预付和供应链金融贷款”。
3. 示例金额展示清晰，例如 100 万采购单拆分为 20 万预付和 80 万贷款。
4. 页面风格与现有后台表格、卡片和状态标签一致。
5. 不新增真实贷款、支付、审批、还款或结算逻辑。
