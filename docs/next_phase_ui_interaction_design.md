# 下一阶段 UI/交互整体设计交付说明

## 1. 设计目标

本文档面向主线程与前端线程，用于下一阶段登录、注册、Dashboard、标准库、供货商、采购交易、履约结算和权限管理页面的 UI/交互落地。本文只定义界面与交互口径，不新增后端接口，不调整后端模型。

核心目标：

- 统一下一阶段页面的视觉系统、布局系统、按钮状态、浮层策略和响应式口径。
- 让前端先实现“可交互样子”时有清晰边界，避免每页各自发散。
- 保留已确认主页和物料需求入口，后续页面只做视觉衔接和路由承接。

硬性设计结论：

- 默认视觉统一为主页浅色系 + 蓝色主调，不再扩展新的主色系。
- 后续新页面必须向现有物料需求入口靠齐：白色主背景、浅蓝灰页面底、蓝色主动作、细边框、轻阴影、紧凑表格、清晰工具栏，不能和物料需求入口形成两套风格。
- 业务页面以浅色采购工作台为主，体现专业船供、港口运营和供应链协同，不做促销商城，也不做灰旧 ERP。
- 业务工作台统一使用默认收起的左侧菜单，可展开为抽屉式完整菜单。
- 空间策略固定为：高频操作常驻页面，详情进入抽屉，短确认进入弹窗，大量编辑和大表格进入放大工作区，低频辅助信息进入折叠区。
- 列表查询页不展示无意义固定船舶上下文；船舶、港口、ETA、ETD 等字段只有在真实业务对象存在时进入详情/流程上下文，若用于列表查询，必须按实际列表列设计为输入框、下拉框或日期时间范围筛选。
- 页面可见操作按钮默认用图标代替文字，图标必须和动作语义一致；完整中文/英文动作文案放在 tooltip、`aria-label` 和国际化文件中。
- 每个业务页面都移除顶部独立介绍区，不展示模块小字、页面大标题和说明副标题；顶部导航下面直接顶上实际业务内容。
- 按钮、Tab、表格列、空态、错误态必须考虑中文和英文长度，语言切换入口固定放在顶部导航或用户菜单。

首页服务轮播补充：

- 首页首屏服务展示从单一供货商板块扩展为 6 屏轮播：供货商服务、物料采购服务、伙食采购服务、船员服务、气象服务、驳船服务。
- 最终视觉风格以用户本地录屏 `C:\Users\KING富贵儿\Downloads\屏幕录制 2026-06-07 182613.mp4` 为第一参考；只借鉴动效、节奏、构图和大气感，不照搬视频原内容。原登录页保留为第一页。
- 轮播需具备动态大气效果，强调舟山港区、锚地、外锚/内锚、夜间港区、供应链轨迹、风浪潮汐、交通船航线等本地海事属性；不使用纯抽象渐变或普通促销商城图。
- 左右箭头常驻或悬浮可见，底部或侧边显示 6 个进度点；10 秒自动切换，鼠标悬停暂停，手动切换后重置计时。
- 每一屏必须同步切换标题、副标题、3 到 4 个指标、主视觉和业务入口。完整文案、指标和图像 prompt 以 `docs/page_detail_specifications.md` 的“2A. 首页服务轮播内容规格”为准。

## 2. 全局视觉系统

### 2.1 色彩

主色策略为克制的蓝色工作台，不使用新色系做页面区分。

| 角色 | 用法 |
| --- | --- |
| 背景色 | 页面底色使用白色、浅灰蓝、极浅蓝灰，避免米色、砂色、深色大面积背景。 |
| 主文字 | 深港蓝，用于标题、关键字段、金额、订单号、船名。 |
| 次文字 | 蓝灰色，用于说明、辅助字段、表格次级信息。对比度必须足够。 |
| 主蓝色 | 用于主按钮、当前选中、链接、焦点框、工作台关键动作。 |
| 浅蓝底 | 用于选中行、筛选激活、信息提示和轻量状态底色。 |
| 琥珀色 | 仅用于风险、超时、待补充、靠泊窗口临近。 |
| 红色 | 仅用于失败、拒绝、取消、危险操作。 |
| 绿色 | 仅用于完成、通过、已送达、已签收。 |
| 中性线条 | 用于分区、表格、卡片边界，尽量轻，不做厚重框线。 |

禁止：

- 为不同模块发散一套独立色彩。
- 用高饱和大色块铺满业务页。
- 用红黄绿替代文字说明，状态必须有文案。
- 用商城促销色、渐变文字、装饰光效制造刺激感。

### 2.2 字号与字重

| 层级 | 建议 |
| --- | --- |
| 页面标题 | 22 到 26px，600 到 700 字重，中文不做过大展示字。 |
| 区块标题 | 16 到 18px，600 字重。 |
| 正文与表格 | 13 到 14px，表格密度可略高，但行高不得压迫。 |
| 辅助信息 | 12 到 13px，颜色要保证可读。 |
| 数字指标 | 20 到 28px，只在 Dashboard 或摘要卡使用，不堆成数据大屏。 |

原则：

- 产品 UI 使用稳定字号，不使用随视口剧烈变化的标题。
- 英文标题和按钮比中文更长时，优先换行、截断或 tooltip，不压缩到不可读。
- 表格中长物料名、企业名、规格型号默认两行截断，详情在抽屉或 tooltip 中展开。

### 2.3 间距与密度

| 区域 | 间距 |
| --- | --- |
| 页面外边距 | 桌面 24 到 32px，平板 20px，移动端 16px。 |
| 区块间距 | 16 到 24px。 |
| 表格行高 | 紧凑 42 到 46px，常规 48 到 54px。 |
| 工具栏高度 | 44 到 52px。 |
| 按钮高度 | 常规 36 到 40px，小按钮 32px，移动端触控不低于 44px。 |

密度口径：

- 采购、报价、比价、权限配置允许高密度，但必须分清主次。
- Dashboard 不堆过多图表，优先待办、风险、时间线和下一步。
- 详情信息不平铺在主页面，进入抽屉或折叠区。
- 业务工作台使用满高布局，顶部导航下方的主内容区吃满剩余视口高度。
- 页面最下面的主表格、代码块、矩阵或工作面板必须自适应补满剩余高度，不能只包住少量行后让下方出现大面积空白。

### 2.4 按钮

按钮类型统一：

| 类型 | 使用场景 |
| --- | --- |
| 主图标按钮 | 提交报价、生成订单、提交订单、保存权限、确认送达。每个工作区最多一个主动作，视觉上用主蓝图标按钮承载。 |
| 次图标按钮 | 保存草稿、返回比价、导出、刷新、清空筛选。 |
| 行内图标按钮 | 查看详情、查看日志、展开更多、映射 SKU、图片预览。 |
| 更多菜单 | 低频动作和超过 3 个的并列动作，进入更多菜单，不做一排文字按钮。 |
| 危险图标按钮 | 停用、撤回、作废、取消订单、拒绝报价、删除附件。必须二次确认。 |

图标规则：

- 页面可见按钮默认使用图标表达，文字只进入 tooltip、`aria-label`、确认弹窗标题或必要的表单提交说明。
- 禁止在工具栏、表格行操作、抽屉头部、卡片动作区堆一排文字按钮。
- 常用图标建议：搜索 `Search`，新增 `Plus`，刷新 `RefreshCw`，导入 `Upload`，导出 `Download`，保存 `Save`，提交/发送 `Send`，查看 `Eye`，编辑 `Pencil`，删除 `Trash2`，停用 `Ban`，确认 `Check`，关闭/取消 `X`，放大 `Maximize2`，收起 `Minimize2`，更多 `MoreHorizontal`，图片 `Image`。
- 图标必须让用户一眼理解动作；无法一眼理解的动作进入“更多”菜单，tooltip 必须写清动作对象。

所有按钮状态必须覆盖：

- `default`：正常可用。
- `hover`：背景或边框轻微变化。
- `focus`：清晰焦点框，键盘可见。
- `active`：按下态有即时反馈。
- `loading`：显示处理中并防重复触发。
- `disabled`：降低强调，并说明禁用原因。

英文适配：

- 主动作图标按钮固定尺寸，英文长文案只在 tooltip、弹窗或辅助说明中出现。
- 图标按钮优先用图标承载，tooltip 展示完整中英文文案。
- 工具栏按钮过多时折叠进“更多”，不挤压主按钮。

### 2.5 表格

通用表格能力：

- 顶部工具栏：搜索、筛选、刷新、导出、批量操作、放大/收起。
- 表头：支持排序、筛选状态提示、列宽稳定。
- 行：支持选中、hover、状态标签、行详情入口。
- 空态：说明原因和下一步动作。
- 错误态：说明失败原因并提供重试。
- 加载态：骨架行或局部遮罩，不整页空白。

大表格口径：

- 需求清单、供货商产品、报价明细、比价矩阵、权限配置必须有放大工作区。
- 表格或代码块作为页面底部主区域时，容器必须 `flex: 1; min-height: 0`，高度补满当前工作台剩余空间。
- 数据行不足时，容器背景和边框延伸到底部；数据行超出时，容器内部滚动，表头可 sticky。
- 放大后保留筛选、选中、滚动位置和输入内容。
- 移动端不得强行压缩完整表格，改为卡片行、折叠行或横向矩阵替代视图。

### 2.6 表单

表单布局：

- 短表单使用单列或两列。
- 注册、下单、权限配置等长表单使用分组、步骤、折叠区或放大工作区。
- 必填项、格式错误、禁用原因必须就近显示。
- 保存、提交、导入时对当前表单区域显示遮罩或禁用态。

字段组：

- 基础信息常驻。
- 高级设置、附件、日志、历史记录默认折叠。
- 大量编辑进入放大工作区，不在普通抽屉里塞满字段。

### 2.7 卡片与状态标签

卡片仅用于：

- Dashboard 指标。
- 页面摘要。
- 订单上下文。
- 风险提醒。
- 三类入口或少量重点动作。

状态标签：

- 形态统一为小号圆角标签，不使用大色块。
- 状态必须有文字，不能只靠颜色。
- 业务状态色固定，不按页面变色。

建议状态映射：

| 状态 | 视觉 |
| --- | --- |
| 草稿、待处理 | 中性灰蓝。 |
| 进行中、待报价、待比价 | 蓝色。 |
| 待补充、超时、窗口临近 | 琥珀色。 |
| 已提交、已下单、已送达、已归档 | 绿色。 |
| 异常、拒绝、取消、失败 | 红色。 |

### 2.8 浮层

浮层层级固定：

`Tooltip < Dropdown < Popover < Drawer < Modal < Confirm`

使用规则：

- Tooltip：解释图标按钮、禁用原因、截断文本。
- Dropdown：更多操作、轻筛选、排序。
- Popover：日期范围、小型筛选、状态说明。
- Drawer：详情、日志、关联信息、单项编辑。
- Modal：短确认、上传结果、拒绝原因、异常上报。
- Confirm：危险动作二次确认。

## 3. 全局布局

### 3.1 顶部导航

顶部导航常驻于所有工作台页面，包含：

- 平台名称或 logo。
- 当前模块名称。
- 全局搜索入口，后续可预留。
- 语言切换入口，放在顶部导航右侧或用户菜单中。
- 通知或风险提醒入口。
- 用户菜单：用户、企业、角色、退出登录。

主页和登录页可沿用公开页样式，但语言切换必须有明确位置。

### 3.2 左侧抽屉菜单

业务工作台默认左侧菜单收起为窄栏或图标栏。

收起态：

- 展示模块图标。
- 当前模块高亮。
- hover 时显示 tooltip。
- 不挤压主工作区。

展开态：

- 以抽屉方式覆盖或轻推内容区域。
- 展示完整菜单名称、分组和角色过滤后的入口。
- 展开、收起动效 150 到 250ms。
- 移动端为侧滑抽屉，带遮罩，Esc 或点击遮罩可关闭。

### 3.3 工作区

工作区由四层组成：

- 主内容上顶：顶部导航下方不再放独立 PageHeader，直接进入指标摘要、筛选工具栏、数据表格或当前流程上下文。
- 上下文条：仅用于具体需求、询价、报价、比价、订单、送船等详情或流程页，展示船名、港口、靠泊、离泊、状态、截止时间。
- 页面工具栏：搜索、筛选、刷新、主动作。列表页按真实列表列配置输入框、下拉和日期范围筛选，不用固定信息卡替代查询条件。
- 主内容区：表格、矩阵、表单或时间线。位于底部的主内容区必须自适应补满剩余高度，内部滚动。
- 辅助区：摘要、风险、下一步、折叠信息。

工作区不能堆满所有内容。能进抽屉的详情，不常驻。能进折叠区的历史，不抢主空间。

列表页明确禁止：

- 不展示固定演示值 `M/V OCEAN EAST`、`Zhoushan`、`2026-06-04 14:30`、`2026-06-05 06:00`。
- 不把船舶、港口、ETA、ETD 做成每页常驻信息块；如果列表需要这些条件，放入工具栏筛选。
- 不用与实际表格列无关的假字段占据首屏。

### 3.4 详情抽屉

详情抽屉建议从右侧打开，宽度：

- 桌面：420 到 560px。
- 大详情：640px。
- 平板/移动：全宽抽屉。

承载内容：

- IMPA 物料详情。
- 供货商档案详情。
- SKU 映射详情。
- 需求/询价/报价/订单详情。
- 送船状态时间线。
- 操作日志。

抽屉底部可放与当前详情相关的局部动作，不能放全页主动作。

### 3.5 弹窗

弹窗仅用于短任务：

- 危险动作确认。
- 提交前风险确认。
- 拒绝报价原因。
- 撤回询价原因。
- 异常上报。
- 上传结果。
- 轻量新增或选择。

弹窗不承载大表格和复杂表单。超过 6 到 8 个字段时，应改为抽屉或放大工作区。

### 3.6 放大工作区

放大工作区用于高密度任务：

- 大型表格。
- 报价明细。
- 比价矩阵。
- 权限配置。
- 长表单编辑。
- 物料匹配明细。

进入放大态后：

- 临时隐藏或压缩左侧菜单、摘要卡和低频区。
- 顶部保留上下文条和返回原尺寸按钮。
- 保留当前筛选、选中、滚动、输入。
- 支持 Esc 或明确按钮退出。

### 3.7 折叠区

折叠区用于低频信息：

- 高级筛选。
- 附件。
- 历史记录。
- 操作日志入口。
- 说明文案。
- 扩展费用项。

默认收起，展开时不造成页面大幅跳动。

## 4. 页面级设计方案

### 4.1 主页与物料需求入口

复用口径：

- 主页复用现有 Vue 页面，不重做。
- 物料需求入口复用现有 Vue 页面和业务结构，不推翻已确认结构。
- 物料需求入口允许继续高级化视觉处理：层级、留白、按钮反馈、表格密度、遮罩、放大态、文本溢出和动效。
- 伙食采购入口与物料入口视觉保持同一体系，但业务链路必须先询价、再报价、再比价，不提供日价直比入口。
- 物料入口可在标准编码匹配、SKU 覆盖和日价有效时进入预比价或快速比价；伙食入口的“进入比价”只能在本次询价报价回收后出现。

按钮分组：

| 分组 | 按钮 |
| --- | --- |
| 常驻 | 进入伙食采购、进入物料采购、进入服务入口、登录、注册、语言切换。 |
| 物料入口常驻 | 上传采购清单、选择文件、重新上传、物料查找、新增物料、导出、比价、筛选匹配状态、刷新。 |
| 伙食入口常驻 | 上传伙食清单、选择文件、重新上传、创建询价、选择供货商、刷新、语言切换。 |
| 弹窗 | 文件上传结果、物料查找、新增物料短表单。 |
| 放大态 | 物料匹配明细放大/收起。 |

验收重点：

- 与后续工作台视觉衔接，但不重新设计业务结构。
- 上传、导出、比价需要 loading 或禁用态。
- 伙食需求未询价或未收到有效报价时，比价按钮不出现或禁用，并说明“需先完成本次询价报价”。
- 英文文案不能挤压顶部入口和明细工具栏。

### 4.2 登录页

布局草图：

```text
公开页顶部导航：Logo / 语言切换 / 注册
┌──────────────────────────┬────────────────────┐
│ 港口业务氛围 + 平台信任信息 │ 登录表单             │
│ 日/夜视觉切换提示           │ 账号 / 密码 / 登录    │
│ 采购链路摘要               │ 忘记密码 / 注册      │
└──────────────────────────┴────────────────────┘
```

空间策略：

- 主区域：登录表单。
- 右侧/左侧品牌区：港口运营气质和平台可信信息，不喧宾夺主。
- 弹窗：忘记密码初步确认、登录失败安全提示。
- 折叠区：无。
- 放大区：无。

按钮分组：

## 5. 重点交互口径

### 5.1 Tab 切换

- 使用 150 到 250ms 下划线移动、轻量滑动或淡入淡出。
- 不允许直接闪屏切换。
- 切换时保留当前 Tab 内的筛选和滚动，除非用户主动刷新。
- 英文 Tab 名过长时可横向滚动或换成图标 + tooltip，不压缩到不可读。

### 5.2 抽屉打开

- 从右侧滑入，150 到 250ms。
- 主页面保留，不刷新，不丢选中行。
- 抽屉内首个可操作元素获得焦点。
- Esc 关闭，移动端可点击遮罩关闭。

### 5.3 弹窗确认

- 弹窗只做短确认和短表单。
- 危险操作必须展示对象名称、影响范围、原因输入。
- 弹窗按钮必须明确：如“确认停用供应商”“取消”。
- 提交中禁用按钮并显示 loading。

### 5.4 行展开

- 行展开用于少量补充信息，动效 150 到 200ms。
- 展开不应造成整页明显跳动。
- 大内容不能塞进行展开，应打开抽屉或放大区。

### 5.5 放大/收起

- 放大入口统一放在表格或工作区工具栏右侧。
- 放大后保留上下文条、关键按钮和退出入口。
- 放大前后的筛选、选中、滚动、输入必须保留。
- 退出放大不触发重新请求，除非用户主动刷新。

### 5.6 数据加载遮罩

- 首屏加载使用骨架屏。
- 表格刷新使用表格局部遮罩。
- 保存、提交、导入、批量处理使用当前工作区遮罩或按钮 loading。
- 遮罩文案必须国际化，如“正在提交报价”“Uploading file”。
- 遮罩不能挡住全局导航和紧急返回入口。

### 5.7 国际化与长文本

- 顶部导航或用户菜单必须有语言切换。
- 所有按钮、Tab、表格列、空态、错误态、Toast、Dialog、Tooltip 使用翻译 key。
- 英文长度按中文 1.6 到 2 倍预留空间。
- 工具栏按钮过多时折叠进更多菜单。
- 表格列名长时允许两行，数据长时两行截断 + tooltip。
- 空态和错误态英文长文案应限制行宽，不挤压操作按钮。

## 6. 给前端的实现建议

### 6.1 先做共享组件

建议优先完成以下共享组件，再做页面：

- `WorkbenchLayout`：顶部导航、默认收起左侧菜单、主工作区。
- `CollapsibleSidebar`：收起、展开、移动端侧滑、角色菜单过滤。
- `PageToolbar`：搜索、筛选、主动作图标、更多操作；不承载独立页面大标题和说明文案。
- `DataTable`：loading、empty、error、selection、pagination、row action。
- `ExpandablePanel`：放大/收起、保留上下文、保留状态。
- `DetailDrawer`：统一抽屉。
- `ConfirmDialog`：危险操作确认。
- `LoadingOverlay`：局部遮罩。
- `AnimatedTabs`：统一 Tab 动效。
- `StatusBadge`：状态标签。
- `LanguageSwitch`：顶部语言切换。
- `EmptyState`、`ErrorNotice`、`PermissionState`。

### 6.2 页面先接 UI 状态

在接口未全部完成前，前端页面也要先做完整 UI 状态：

- loading。
- empty。
- error。
- permission denied。
- disabled reason。
- submitting。
- success feedback。

写操作如登录、提交报价、生成订单、提交订单不能静默 mock。接口未接入时显示“接口未接入”类错误。

### 6.3 权限与按钮清单

每页实现前先列按钮清单，至少包含：

- 按钮文案 key。
- 可见角色。
- 可见状态。
- 禁用条件。
- 禁用原因 key。
- loading 文案 key。
- 是否危险操作。
- 是否需要二次确认。

### 6.4 响应式优先级

优先验收：

- 1440px：标准桌面。
- 1280px：紧凑桌面。
- 768px：平板，抽屉全宽或半宽。
- 390px：手机，菜单侧滑，表格转卡片或横向替代。

## 7. UI 验收清单

全局验收：

- 默认视觉为主页浅色系 + 蓝色主调，不出现新主色系。
- 新页面视觉必须和物料需求入口同一体系，不能出现明显割裂的卡片、按钮、表格或背景风格。
- 页面有船供和港口运营气质，不像促销商城，不像灰旧 ERP。
- 顶部导航下面不出现独立页面介绍头，不展示类似 `Dashboard / Dashboard / 汇总待办...` 的标题说明区。
- 主页和物料需求入口复用现有 Vue 页面和业务结构。
- 列表页不得展示固定假的船舶、港口、ETA、ETD；这些字段如果需要查询，必须是筛选项。
- 业务工作台左侧菜单默认收起，可展开为抽屉，移动端侧滑。
- 语言切换入口在顶部导航或用户菜单中。

布局验收：

- 高频操作常驻页面。
- 详情进入抽屉。
- 短确认进入弹窗。
- 大量编辑和大表格进入放大工作区。
- 低频辅助信息进入折叠区。
- 关闭浮层后不丢筛选、输入、选中、滚动位置。

按钮验收：

- 每页有按钮/动作入口清单。
- 页面可见操作默认用图标按钮，不出现整排文字按钮。
- 主动作每个工作区最多一个，并使用主蓝图标按钮。
- 图标按钮有 tooltip 和 `aria-label`。
- tooltip、`aria-label` 和 loading/disabled 文案均来自国际化文件。
- 按钮具备 hover、focus、active、loading、disabled。
- 禁用按钮有原因说明。
- 危险按钮二次确认。

状态验收：

- 每页有 loading、empty、error、permission、submitting。
- 保存、提交、导入、批量处理有遮罩或禁用态。
- 错误态有原因和重试或替代路径。
- 空态说明业务原因并给下一步动作。

动效验收：

- Tab 切换 150 到 250ms，不闪屏。
- 抽屉打开 150 到 250ms。
- 弹窗出现克制，不做夸张动效。
- 行展开轻量，不造成明显跳动。
- 支持减少动态效果。

国际化验收：

- 中英文切换不刷新页面。
- 当前路由、筛选、表单、弹窗状态不丢。
- 英文长文案不撑爆按钮、Tab 和表格列。
- 表格列、空态、错误态、遮罩文案均可翻译。
- 缺失翻译 key 在开发环境可发现。

页面验收：

- Dashboard：四类角色重点不同，必须有待办、风险、下一步。
- IMPA 标准库：一级分类 + 物料列表 + 行内下推详情，不做商品商城，不使用右侧详情抽屉。
- 供货商信息：突出服务港口、品类、资质、响应率。
- 供货商产品：SKU 表格展示缩略图、核心属性、价格、库存、IMPA 映射状态；SKU 详情抽屉展示图片、属性组、IMPA 映射和历史报价。
- 需求清单：承接物料入口，支持放大明细和创建询价。
- 询价单：供应商选择、发送、撤回、报价进度清楚。
- 询价/报价：明细中必须展示价格对应的属性组合摘要和图片缩略图，完整属性进入抽屉，不把大量属性平铺挤满表格。
- 报价：逐项报价、缺货、替代、属性组合、提交校验清楚。
- 比价：价格、交期、可供数量、属性组合、替代风险同屏比较；矩阵内展示图片缩略图和属性摘要，点击图片可打开大图预览。
- 伙食比价：伙食需求未完成本次询价和有效报价回收前，比价入口不出现或禁用，并提示需先完成询价报价。
- 比价策略：比价页展示前五家供货商排名和排名依据，支持最低报价混采与集中采购切换，右侧摘要同时展示混采总价、集中采总价、推荐方案、缺货/替代/交付风险。
- 下单：右侧费用摘要和提交校验常驻。
- 送船/驳船任务：状态时间线、异常上报、签收上传首屏可达。
- 费用结算归档：费用、发票、付款、归档和日志可追溯。
- 权限管理：菜单树、操作权限、数据范围三栏清楚。
