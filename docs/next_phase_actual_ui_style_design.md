# 下一阶段实际 UI 样式设计交付

## 1. 交付定位

本文档用于前端实现下一阶段真实 UI 样式。它不是原则说明，而是可直接转成 Vue 组件、CSS token、页面布局和交互状态的样式规范。

覆盖页面：

- 登录、注册、Dashboard。
- IMPA 标准库。
- 供货商信息、供货商产品。
- 需求清单、询价单、报价、比价、下单。
- 送船/驳船任务、费用结算归档、权限管理。

固定约束：

- 默认视觉沿用主页浅色系 + 蓝色主调。
- 不重新设计已确认主页和物料需求入口，只做视觉高级化和衔接。
- 新页面必须向物料需求入口的浅色专业采购工作台靠齐：白色主背景、浅蓝灰页面底、蓝色主动作、细边框、轻阴影、紧凑表格、清晰工具栏。
- 业务工作台左侧菜单默认收起，可抽屉展开。
- 不把所有内容堆在页面上，继续使用抽屉、弹窗、放大工作区、折叠区。
- 供货商产品、询价、报价、比价必须展示 SKU 图片缩略图和属性摘要，完整属性进抽屉，大图进预览弹窗。
- 伙食采购必须先询价、再报价、再比价，未完成报价回收前禁用或隐藏比价入口。
- 所有样式要承受英文长度，按钮、Tab、表格列不得被英文撑爆。
- 列表页不展示无意义固定船舶上下文信息；列表查询条件必须按真实列表主列设计为输入框、下拉或日期范围。
- 操作按钮默认使用图标代替文字，图标必须与动作语义一致，并提供 tooltip 和 `aria-label`。

## 3. 全局布局样式

### 3.1 WorkbenchLayout

桌面结构：

```text
┌──────────────────────────────────────────────┐
│ TopNav 56px                                  │
├──────┬───────────────────────────────────────┤
│ 64px │ ContextBar（仅流程详情页）/ Toolbar    │
│ 菜单 │ Summary / Filter / Data Block         │
│ 收起 │ Main Work Area                        │
│      │ Drawer / Expanded Panel / Modal       │
└──────┴───────────────────────────────────────┘
```

样式规格：

- 顶部导航高度 56px，白底，底部 1px 边线。
- 收起菜单宽度 64px，展开抽屉宽度 260px。
- 主内容区背景 `--color-bg-page`，padding 24px。
- 工作区最大宽度不强制居中，业务页面使用全宽工作台。
- 工作台必须使用满高布局：`TopNav` 下方的主区域高度为剩余视口高度，内容列使用 `display: flex; flex-direction: column; min-height: 0`。
- 页面下方主代码块、表格块、矩阵块或工作面板必须自适应补满剩余高度，不允许只包住少量行后在底部留下大面积空白。
- 自适应补高后，滚动发生在表格/代码块内部，不让整个页面出现无意义长空白。
- 移动端菜单变侧滑抽屉，主内容 padding 16px。

### 3.2 顶部导航

视觉：

- 白色背景，底边线 `--color-border-subtle`。
- 左侧 logo 使用深港蓝字色，logo mark 可用主蓝底。
- 模块名称使用 15px / 600。
- 右侧图标按钮 36px 正方形，hover 背景 `--color-bg-hover`。
- 语言切换放在用户菜单左侧或用户菜单内第一组。

状态：

- 当前模块不使用大色块，用主蓝色文字或轻背景。
- 通知/风险图标有红点时使用 danger 小点，不使用闪烁动画。

### 3.3 默认收起左侧抽屉菜单

收起态：

- 宽 64px。
- 背景 `#ffffff`。
- 右边线 `--color-border-subtle`。
- 图标按钮 40px，居中。
- 当前菜单：浅蓝底 + 主蓝图标。
- hover 显示 tooltip，150ms 淡入。

展开态：

- 宽 260px，抽屉覆盖主内容或轻推主内容，具体由前端实现选择。
- 菜单分组标题 12px，灰蓝色。
- 菜单项高度 40px，圆角 8px。
- 展开/收起动效 180ms ease-out。
- 移动端全高侧滑，宽度 280px 或 82vw，带遮罩。

### 3.4 页面头部与上下文条

PageHeader：

- 业务工作台页面不再使用独立 PageHeader。
- 每个页面顶部都要拿掉“模块小字 + 页面大标题 + 说明副标题”这一组内容，例如 `Dashboard / Dashboard / 汇总待办...`。
- 顶部导航下方直接顶上实际业务内容：指标摘要、筛选工具栏、数据表格、当前流程上下文或主工作区代码块。
- 页面主动作放到实际工作区的工具栏右侧，不放在独立介绍头里。
- 如果需要说明页面用途，放入空态、帮助抽屉或低频折叠区，不常驻首屏顶部。

ContextBar：

- 高度 48 到 56px。
- 白底或浅蓝底，1px 边框，圆角 8px。
- 用于船舶、港口、靠泊、离泊、报价截止、状态。
- 信息项采用 `label + value`，label 12px，value 13px / 600。
- 移动端横向滚动，不压缩字段。
- 只在具体需求单、询价单、报价单、订单、送船任务等详情页或流程页展示。
- 列表页、管理页、标准库页、供货商页、权限页不展示固定船舶/港口/ETA/ETD 上下文条。
- 禁止在列表页常驻展示 `M/V OCEAN EAST`、`Zhoushan`、`2026-06-04 14:30`、`2026-06-05 06:00` 这类无意义演示值。
- 如果列表页需要按船舶、港口、ETA、ETD 查询，应放入工具栏输入框、下拉或高级筛选，不作为信息卡展示。

### 3.5 页面工具栏

工具栏样式：

- 白底，1px 边框，圆角 8px。
- 高度 48px，复杂页面可 56px。
- 左侧搜索和筛选，右侧主动作、导出、刷新、放大。
- 图标按钮固定 32 或 36px。
- 超过 5 个动作时，低频动作进入“更多”菜单。
- 列表页工具栏按实际列表列设计检索：订单号、需求单号、询价单号、SKU 编码、IMPA 编码、供货商、船舶、港口、状态、时间范围等。
- 不使用固定假业务信息替代筛选条件。

搜索框：

- 高度 36px。
- 宽度桌面 260 到 360px。
- 前缀搜索图标。
- 清空按钮有 tooltip。

筛选按钮：

- 筛选激活时显示浅蓝底和小计数。
- 高级筛选进入 Popover 或折叠区，不常驻铺开。

## 4. 组件样式

### 4.1 按钮

按钮总体规则：

- 页面可见操作按钮默认使用图标代替文字，尤其是工具栏、表格行操作、抽屉头部、卡片动作和弹窗底部动作。
- 不再做一排文字按钮；多个动作并列时使用图标按钮组，低频动作进入“更多”菜单。
- 图标必须与动作语义一致：新增 `Plus`，搜索 `Search`，筛选 `SlidersHorizontal`，刷新 `RefreshCw`，导入 `Upload`，导出 `Download`，保存 `Save`，提交/发送 `Send`，查看 `Eye`，编辑 `Pencil`，删除/作废 `Trash2`，停用 `Ban`，启用/确认 `Check`，关闭 `X`，放大 `Maximize2`，收起 `Minimize2`，更多 `MoreHorizontal`，图片预览 `Image`。
- 每个图标按钮必须有 tooltip 和 `aria-label`，tooltip 使用国际化 key。

主动作图标按钮：

```text
尺寸 36-40px
圆角 6px
背景 主蓝色
图标 白色 18px
```

状态：

- hover：背景加深一级。
- focus：2px 主蓝外圈，外圈与按钮间隔 2px。
- active：轻微下沉或背景加深，不做缩放夸张效果。
- loading：图标替换为 spinner，tooltip 文案改为“提交中”类 key。
- disabled：浅灰蓝底，图标灰蓝，tooltip 说明原因。

次动作图标按钮：

- 白底，1px 边框，主文字色。
- hover 为浅蓝底。
- 用于导出、返回、清空、保存草稿。

危险按钮：

- 红色边框或红色文字为主。
- 真正删除/取消类确认弹窗里的主危险动作可用红底。

图标按钮：

- 32 或 36px 正方形。
- 默认透明，hover 浅蓝底。
- 必须有 `aria-label` 和 tooltip。

### 4.2 Tab

样式：

- Tab 容器底边线 `--color-border-subtle`。
- Tab 高度 44px。
- 当前 Tab：主蓝文字 + 2px 下划线。
- 非当前 Tab：灰蓝文字。
- hover：浅蓝文字或浅蓝底。

动效：

- 下划线移动 180ms。
- 内容切换 150ms 淡入。
- 不做整页闪屏。
- 英文长 Tab 可横向滚动，最小宽度 96px，最大宽度 180px，超出省略 + tooltip。

### 4.3 筛选区

基础筛选常驻工具栏，高级筛选折叠。

筛选控件：

- Select 高度 36px。
- DateRange 宽 240px。
- 多选状态用 Tag 展示，超过 3 个折叠为“+N”。
- 高级筛选展开区域白底、上边线、padding 16px。

### 4.4 数据表格

表格容器：

- 白底，1px 边框，圆角 8px。
- 表头背景 `--color-bg-subtle`。
- 表头文字 12px / 600，深灰蓝。
- 单元格文字 13px。
- 行高常规 48px，带图片时 56 到 64px。
- hover 行背景 `--color-bg-hover`。
- selected 行背景 `--color-bg-selected`。
- 位于页面底部的主表格/代码块容器必须 `flex: 1; min-height: 0`，并根据剩余视口高度自动补满。
- 表格内容不足时，容器仍然撑满可用高度；空白区域保留在容器内部，边框和背景完整延伸到底部。
- 表格内容超出时，使用容器内部滚动，表头可 sticky，避免页面外层滚动和内部滚动互相打架。

固定列：

- 选择框列 44px。
- 图片列 64px。
- 操作列 96 到 140px，固定右侧。

长文本：

- 品名和规格默认两行截断。
- 英文长列名允许两行。
- 完整内容通过 tooltip 或详情抽屉。

图片缩略图：

- 尺寸 40 x 40px。
- 圆角 6px。
- 背景浅灰蓝。
- object-fit: cover。
- 无图显示占位图标和浅蓝灰底。
- hover 出现放大图标或轻蒙层。
- 点击打开图片预览弹窗。

属性摘要：

- 表格内最多显示 3 个属性 chip。
- chip 高度 22px，圆角 4px，浅蓝灰底。
- 超出显示 `+N 属性`，点击打开属性详情抽屉。

### 4.5 状态标签

规格：

- 高度 22 到 24px。
- padding 0 8px。
- 圆角 pill。
- 字号 12px / 600。
- 左侧可有 6px 状态点。

状态样式：

- 进行中：蓝色文字 + 浅蓝底。
- 待处理：灰蓝文字 + 浅灰底。
- 风险：琥珀文字 + 浅琥珀底。
- 完成：绿色文字 + 浅绿底。
- 异常：红色文字 + 浅红底。

### 4.6 详情抽屉

规格：

- 桌面宽 520px。
- 大详情 640px。
- 移动端全宽。
- 白底，左侧阴影。
- Header 高 56px，底边线。
- Body padding 20px，分组间距 20px。
- Footer sticky bottom，白底，上边线，padding 12px 16px。

内容分组：

- 摘要区：对象名称、状态、关键编码。
- 信息组：两列 description list。
- 属性组：使用 Key/Value 列表或属性 chip 分组。
- 图片组：缩略图网格，点击预览。
- 历史记录：时间线样式，默认折叠最近 3 条。

### 4.7 确认弹窗

规格：

- 宽 420 到 520px。
- 圆角 10px。
- 标题 18px / 700。
- 正文 14px。
- Footer 右对齐按钮。
- 危险操作要展示对象名称、影响范围和原因输入。

禁用：

- 不用弹窗承载大型表格。
- 不用弹窗做长表单。

### 4.8 图片预览弹窗

用途：

- SKU 图片。
- 报价明细图片。
- 比价矩阵图片。
- 发票或单证预览可复用同一视觉框架。

规格：

- 遮罩 `--color-bg-mask`。
- 弹窗最大宽度 80vw，最大高度 86vh。
- 图片区域深色中性背景 `#071d33` 或白底，按图片类型选择。
- 顶部显示 SKU 名称、Item No.、图片序号。
- 底部或右侧显示属性摘要：规格、包装、尺寸、重量、库存。
- 支持上一张、下一张、下载、关闭。
- Esc 关闭，点击遮罩关闭。

### 4.9 Loading 遮罩

区块遮罩：

- 背景 rgba(255,255,255,0.72)。
- 可选 backdrop blur 2px，但不做玻璃效果。
- 中间显示小 spinner + 文案。
- 遮罩区域保持原布局，不跳动。

表格加载：

- 首次加载用骨架行。
- 刷新用局部遮罩。
- 提交时按钮 loading + 表单区域禁用。

### 4.10 放大工作区

规格：

- 占据主工作区完整宽高。
- 顶部保留上下文条和退出按钮。
- 隐藏右侧摘要或将摘要压缩为顶部小条。
- 表格高度撑满可用空间，内部滚动。
- 退出后恢复原筛选、选中、滚动位置。

适用：

- 供货商产品表。
- 需求清单表。
- 报价明细表。
- 比价矩阵。
- 权限配置。

### 4.11 空态、错误态、权限态

空态：

- 白底区域居中或左上友好布局。
- 图标使用 lucide 线性图标，大小 36 到 44px。
- 标题 16px / 700。
- 描述 13px，最多两行。
- 主动作按钮明确，如“导入采购清单”“新增 SKU”。

错误态：

- 浅红或浅琥珀提示条。
- 显示错误原因和重试按钮。
- 不直接显示技术堆栈。

权限态：

- 标题说明“当前账号无权访问该页面”。
- 显示角色、企业和建议操作。
- 可提供“返回 Dashboard”或“联系管理员”。

## 5. 页面实际样式

### 5.1 登录

视觉：

- 左侧 52% 为浅蓝港口作业氛围区，可用已有首页视觉语言，不新增暗色主视觉。
- 右侧 420px 表单面板，白底，无厚重阴影，使用 1px 边框。
- 页面背景为浅蓝灰渐变，但不使用装饰光球。

表单：

- 输入框高 40px。
- 登录按钮满宽 40px。
- 错误提示在输入框下方，不用 toast 代替字段错误。
- 语言切换在右上角。

移动端：

- 单列布局。
- 品牌区压缩为 120px 顶部条。
- 表单左右 padding 20px。

### 5.2 注册

视觉：

- 使用三步流程条，步骤条为横向浅蓝线。
- 主表单白底边框卡，右侧审核说明为浅蓝底信息栏。
- 角色选择使用分段控件，不用大卡片堆叠。

长表单：

- 企业信息、服务能力、资质文件分组。
- 资质上传区域为虚线边框 + 文件列表。
- 文件多时进入放大上传管理区。

### 5.3 Dashboard

视觉：

- 顶部一行角色化待办摘要，4 个以内指标。
- 中区使用双栏：左侧待办和风险，右侧船期或送船时间线。
- 下方为订单/任务列表。
- 指标卡白底边框，数值用主蓝或风险色，不使用大屏炫光。

角色差异：

- 船代：重点是待匹配、待询价、待比价、待下单、待送船。
- 供货商：重点是待报价、报价截止、待确认订单、缺货替代。
- 驳船代理：重点是待调度、已出发、异常、签收。
- 管理员：重点是企业审核、异常订单、供应商响应、全局风险。

### 5.4 IMPA 标准库

布局：

```text
Toolbar
┌──────────────┬────────────────────────────┐
│ 一级分类 240px │ 物料列表                   │
└──────────────┴────────────────────────────┘
物料详情：当前行下方下推展开
```

分类树：

- 白底，右边线。
- 分类项高度 34 到 38px，尽量紧凑。
- 一级品类文字 12 到 13px，编码 600 字重，名称单行省略号，不换行。
- 数量右对齐，使用 12px 到 13px，避免挤压名称。
- 当前分类浅蓝底，左侧无粗色条，使用图标/文字强调。

码段展示：

- 不展示页面上方二级码段卡片、按钮区或横向码段区。
- 二级编码只作为表格列、筛选字段或详情字段存在，不作为主视觉入口。
- 点击一级分类后，右侧直接展示该一级下真实物料列表。
- 工具栏搜索框必须支持 IMPA 编码、中文/英文物料名称、规格直接查询。

物料列表：

- 编码列 110px。
- 名称规格列自适应。
- 单位列 80px。
- SKU 覆盖列 100px。
- 状态列 90px。
- 列表使用浅色斑马纹：单数行白底，双数行极浅蓝灰底，色差克制但可区分。
- hover 行背景略深于斑马纹，不破坏选中态。
- 查看详情时不打开右侧抽屉，在当前行下方插入展开行，展开行占满表格宽度。
- 展开行背景使用白底或极浅蓝底，顶部 1px 分隔线，内容用紧凑字段网格展示。
- 展开/收起动效 150 到 200ms，可用高度、透明度或轻微位移动效，避免整表闪跳。

行内详情：

- 顶部显示 IMPA 编码和中英文名。
- 中部显示规格、单位、分类、别名、供应商覆盖。
- 底部按权限显示“映射到我的 SKU”或“维护物料”。

### 5.5 供货商信息

列表样式：

- 第一列供货商名称 + 资质状态。
- 服务港口用最多 3 个 chip，超出 `+N`。
- 响应率用小型进度条，不用大图表。
- 最近报价时间使用相对时间和具体时间 tooltip。

详情抽屉：

- Header 展示企业名称、合作状态、资质状态。
- Tab：基础信息、资质、联系人、服务港口、产品 SKU、历史报价、履约记录。
- 产品 SKU Tab 内只展示摘要和“查看产品”入口，不塞完整产品表。

### 5.6 供货商产品

表格视觉：

```text
图片  SKU 信息             属性摘要              价格/库存      IMPA 映射      操作
40px  名称 + Item No.      规格/包装/尺寸 +N     价格 + 库存     已映射/待确认   编辑
```

列规格：

- 图片列 64px。
- SKU 信息列 260 到 340px。
- 属性摘要列 280 到 360px。
- 价格/库存列 150px。
- IMPA 映射列 220px。
- 操作列 120px。

SKU 信息单元格：

- 第一行：SKU 名称，两行截断。
- 第二行：Item No. 或供应商内部编码，12px 灰蓝。
- 第三行可展示服务港口 chip，最多 2 个。

属性摘要：

- 显示 3 个关键属性：规格、包装、尺寸或重量。
- 超出显示 `+N 属性`。
- 点击属性摘要打开 SKU 详情抽屉。

价格/库存：

- 价格 14px / 700，主文字。
- 币种 12px 灰蓝。
- 库存用状态标签：有库存、低库存、无库存、待更新。

图片：

- 缩略图 40 x 40px。
- hover 显示放大图标。
- 点击打开图片预览弹窗。

SKU 详情抽屉：

- 顶部：主图、SKU 名称、Item No.、映射状态。
- 图片组：主图 + 缩略图列表。
- 属性组：按“基础规格、包装装箱、尺寸体积、重量条码、库存交付”分组。
- IMPA 映射：标准编码、标准名称、匹配状态、映射操作。
- 历史报价：最近 5 条报价，更多进入折叠区。

### 5.7 需求清单

样式：

- 顶部上下文条展示船舶、港口、靠泊、离泊、需求状态。
- 表格首列为原始需求文本，第二列为标准库匹配结果。
- 匹配结果使用蓝色链接样式，可打开抽屉。
- 风险列用状态标签和 tooltip。
- 大表格默认提供放大。

物料图片：

- 如果需求明细已选择供应商 SKU，可在匹配结果旁显示小缩略图。
- 未选择 SKU 时不显示空图片列，避免噪音。

### 5.8 询价单

视觉：

- 上方为询价上下文和报价截止。
- 主表格展示物料、数量、单位、属性摘要、候选供应商覆盖。
- 右侧抽屉展示报价进度。

属性组合：

- 询价明细中属性摘要最多 3 个 chip。
- “选择属性”按钮打开抽屉。
- 属性抽屉内可看图片、规格、包装、尺寸、重量、库存。

伙食询价：

- 伙食入口进入后默认优先创建询价。
- 未发送询价时不出现比价按钮。
- 已发送但未收到有效报价时，比价按钮 disabled，并 tooltip “需先完成本次询价报价”。

### 5.9 报价

报价表格：

```text
物料/图片/属性摘要 | 请求数量 | 可供状态 | 单价 | 税率 | 交付周期 | 缺货/替代 | 操作
```

样式：

- 报价上下文条固定在顶部。
- 截止时间临近时使用琥珀色状态，不用闪烁。
- 明细表支持放大工作区。
- 单价输入框宽 120px，右侧显示币种。
- 可供状态使用 segmented control：可供、缺货、替代、需澄清。

属性：

- 每行展示图片缩略图和属性摘要。
- 点击属性摘要打开详情抽屉。
- 抽屉展示本次报价对应的属性组合和历史报价。

右侧摘要：

- 合计金额。
- 可供项、缺货项、替代项。
- 未填项。
- 提交报价按钮。

### 5.10 比价

页面结构：

```text
ContextBar
StrategyBar: 前五排名 | 最低报价混采 | 集中采购
┌──────────────────────────────┬──────────────┐
│ QuoteMatrix                   │ DecisionSummary │
└──────────────────────────────┴──────────────┘
```

策略栏样式：

- 白底，1px 边框，圆角 8px。
- 左侧展示前五供货商排名按钮。
- 中间为策略 segmented control：
  - 最低报价混采。
  - 集中采购。
- 右侧展示当前策略更新时间或报价有效性。

前五排名：

- 用横向紧凑列表展示 1 到 5 名。
- 每项包含供应商名、总价或覆盖率、风险标签。
- “排名依据”用 Popover 展示：价格、供货完整度、交期、缺货、替代风险。

矩阵样式：

- 物料列固定左侧，供应商列横向滚动。
- 物料单元格包含缩略图、品名、属性摘要、数量。
- 供应商单元格包含单价、总价、交期、可供数量、风险标签。
- 当前策略选中项使用浅蓝底和主蓝边框。
- 缺货项用浅琥珀底，异常项用浅红底。

右侧决策摘要：

- 固定宽 320 到 360px。
- 顶部展示推荐方案。
- 显示混采总价、集中采总价。
- 显示缺货、替代、交付风险计数。
- 显示生成订单主按钮。
- 显示“查看推荐依据”文本按钮。

图片预览：

- 矩阵内缩略图点击打开大图预览弹窗。
- 弹窗侧栏展示属性组合和报价来源。

伙食比价：

- 伙食需求未完成本次询价报价前，不进入该页面，或显示权限/状态态提示。
- 提示文案：需先完成本次询价报价后再进行比价。

### 5.11 下单

样式：

- 左侧主区：订单明细表 + 送船信息表单。
- 右侧 sticky 摘要：费用合计、缺项校验、提交订单。
- 明细表保留图片缩略图和属性摘要，确保订单固化选定 SKU 属性组合。
- 费用摘要白底边框，不做大色块。

禁用态：

- 缺船舶、港口、联系人、计划送达时，提交按钮 disabled。

### 5.12 送船/驳船任务

样式：

- 任务列表左侧，时间线或详情右侧。

- 异常上报按钮常驻在任务详情中。
- 签收上传使用附件列表样式。

移动端：

- 任务列表转卡片。

### 5.13 费用结算归档

样式：

- 费用明细表展示费用类型、金额、状态、关联单证。

- 右侧摘要展示应付、已付、待确认、归档状态。
- 发票预览复用图片/文件预览弹窗。

### 5.14 权限管理

样式：

  - 菜单树。

  - 数据范围说明。

## 6. 交互动效

动效 Token：

```css
:root {
  --motion-fast: 120ms;
  --motion-base: 180ms;
  --motion-slow: 240ms;
  --ease-standard: cubic-bezier(0.2, 0, 0, 1);
}
```

规则：

- 按钮 hover 120ms。
- Tab 切换 180ms。
- 抽屉打开 220ms。
- 弹窗淡入 160ms。
- 行展开 180ms。
- 放大工作区 220ms。
- 图片预览 160ms。
- reduced motion 下取消位移，只保留透明度或瞬时切换。

## 8. 验收清单

视觉：

- 全平台使用浅色蓝主调，无新主色系。
- 业务页高级、清楚、有港口运营气质，不像促销商城，不像旧 ERP。
- 首页和物料需求入口结构未被推翻。

组件：

- 顶部导航、左侧抽屉菜单、工具栏、按钮、Tab、筛选区、数据表格、状态标签样式一致。
- 抽屉、确认弹窗、图片预览弹窗、Loading 遮罩、放大工作区、折叠区样式一致。
- 图标按钮有 tooltip 和 `aria-label`。

SKU 与属性：

- 供货商产品表展示 SKU 缩略图、核心属性、价格、库存、映射状态。
- SKU 详情抽屉展示图片、属性组、IMPA 映射、历史报价。
- 图片点击打开大图预览。
- 询价、报价、比价都能看到价格对应的属性组合。
- 属性多时使用摘要 + 抽屉详情，不平铺挤满表格。

比价：

- 展示前五供货商排名。
- 可查看排名依据。
- 支持最低报价混采和集中采购策略切换。
- 右侧摘要展示混采总价、集中采总价、推荐方案、缺货/替代/交付风险。
- 比价矩阵展示图片缩略图和属性摘要。

伙食采购：

- 伙食入口视觉与物料入口同体系。
- 伙食必须先询价、再报价、再比价。
- 未完成本次有效报价回收前，比价按钮隐藏或禁用，并说明原因。

国际化：

- 英文按钮、Tab、表格列不撑爆布局。
- 长英文进入换行、截断或 tooltip。
- 空态、错误态、禁用原因、loading 文案均使用国际化 key。

状态：

- loading、empty、error、permission、disabled、submitting 均有样式。
- 保存、提交、导入、批量操作有遮罩或禁用态。
- 动效在 150 到 250ms 范围内，Tab 不闪屏。
