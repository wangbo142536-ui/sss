# 船供一站式服务平台原型需求整理

## 1. 文档目的

本文档用于整理船供电商 Web 端原型的页面需求，覆盖：

- 首页
- 集采导入界面
- 集采导入后的采购清单匹配结果界面
- 个人采购界面

本文档先作为需求确认稿。确认前不直接修改原型页面。

## 2. 产品定位

平台整体定位为面向船供业务的一站式电商平台，主要服务分为三类：

- 伙食
- 物料
- 服务

首页需要像电商网站，而不是业务后台。用户进入后应先看到可采购、可搜索、可进入集采或个人采购的商城入口。

企业用户主要使用集采能力，通过上传采购清单完成智能匹配、选择报价策略并生成报价。

个人用户主要使用普通电商采购能力，通过搜索、分类筛选、商品列表和购物车完成采购。

## 2.1 视觉参考方向

网站视觉参考 `https://www.rmsmarineservice.com/` 的国际海事服务风格，但不复制其品牌、文案和页面内容。

可参考的视觉特点：

- 大幅海事场景主视觉，优先使用港口、岛屿、船舶、补给、仓储、物流等真实感图片。
- 深海蓝、白色、少量高亮色作为主色，整体比普通电商更稳重、专业。
- 首页首屏要有明确的一站式服务定位，视觉上体现海事行业可信度。
- 服务或业务入口可以使用清晰图标和卡片，但不要变成后台菜单。
- 可以借鉴其“服务分类 + 数据背书 + 全球/港口服务能力”的表达方式。

需要避免：

- 不使用 RMS 品牌名称、Logo、联系方式、真实分支机构信息。
- 不把首页做成纯公司官网，仍然要保留电商采购入口、搜索、商品、供应商和集采能力。

### 3.3 物料分类

物料分类采用 IMPA / MSG 物料码段体系。首页只显示“物料”一级入口，并在展开或进入物料页后展示码段分类。

首页或集采页可露出常用码段示例：

- 缆绳索具

- 个体防护用品
- 救生消防安全设备
- 通用五金

- 电气器材
- 焊接设备耗材

具体码段和中文名在物料页中展开，不作为首页主视觉内容。

### 3.4 服务分类

服务分类用于承接非商品采购类服务。当前服务入口包括：

- 船员海事服务，建设中
- 报关报备服务
- 港区通行 / 作业协调
- 驳船 / 车辆调度
- 打包运输
- 单证归档 / 核销资料协助

服务中不包含“验货交付”。

## 4. 首页需求

### 4.1 首页定位

首页应呈现为专业船供商城，不是管理后台，不堆放业务流程说明。

首页主题建议：

> 一站式船供服务

首屏 Banner 应使用小干岛、港口、锚地、船舶补给等真实感图片作为背景，不使用纯色渐变作为主视觉。

### 4.2 顶部结构

顶部电商结构包括：

- 平台 Logo
- 搜索框
- 订单入口
- 消息入口
- 购物车
- 供应商入驻
- 语言切换
- 登录 / 注册

搜索框支持：

- 商品名称
- IMPA / MSG 物料编码
- 供应商编码
- 伙食名称
- 服务名称

### 4.3 首屏布局

首屏建议结构：

- 左侧：三类入口，伙食、物料、服务
- 中间：大 Banner，标题为“一站式船供服务”
- 右侧：集采入口、个人专区

右侧入口要求：

`集采入口`

- 面向公司用户
- 进入 Excel 批量采购页面
- 文案突出“上传清单、智能匹配商品与供应商”

`个人专区`

- 面向个人用户
- 进入普通电商商品清单页面
- 文案突出“搜索选购、加入购物车、满额免打包费”

### 4.4 Banner 要求

Banner 内容不要写太多系统说明。

建议文案：

主标题：

> 一站式船供服务

副标题：

> 覆盖伙食、物料与船供相关服务，支持企业集采与个人采购。

主要按钮：

- 开始采购
- Excel 集采
- 查看供应商池

Banner 背景图方向：

- 小干岛
- 港口码头
- 船舶靠港
- 锚地补给
- 船供装卸场景

### 4.5 气象信息专区

首页需要增加气象信息模块，位置在上新产品专区上方，视觉形式与上新产品专区保持一致，作为首页内容模块之一。

默认区域：

- 舟山市

可切换区域：

- 小外围锚地

展示对象：

- 以小干岛周边锚地为卡片个体。
- 重要锚地放在前面。
- 默认优先展示马峙锚地，因为小干岛紧邻马峙锚地。

建议锚地卡片顺序：

- 马峙锚地
- 虾峙门南锚地
- 秀山东锚地
- 条帚门锚地
- 绿华山南锚地
- 马迹山北锚地

展示时间范围：

- 半小时内气象状态。

展示方式：

- 卡片式展示
- 每个锚地一张卡片
- 支持横向滚动或栅格展示
- 支持左右横向滚动或轮播

每张天气卡片字段：

- 锚地名称
- 距小干岛或服务优先级提示，若有
- 最近更新时间，强调半小时内
- 天气图标
- 天气状况
- 降雨概率，若有
- 最高温 / 最低温
- 夜间天气
- 风向
- 风力
- 空气质量或适航提示标签

模块顶部字段：

- 当前选择区域
- 更新时间
- 区域切换按钮，舟山市 / 小外围锚地
- 简短风险提示，例如“风力增强”“能见度良好”“适合作业”等

原型阶段可以使用静态示例数据。后续正式系统需要接入实时气象或港区/锚地气象数据源。

### 4.6 驳船调度专区

首页需要增加“驳船调度”模块，位置在气象信息模块下方、上新产品专区上方。

模块目标：

- 将小、散的驳船公司和交通艇资源统一管理。
- 通过业务量聚合、运输线路优化和一船多供，提高船供运输效率和利润。
- 让用户快速看到不同交通艇在不同日期时间的供应线路、锚地、船舶和作业时间。

展示对象：

- A交通艇
- B交通艇
- C交通艇

每个交通艇占一条示例航线。

模块展示要求：

- 按日期和时间区分调度计划。
- 每条航线展示起点、终点或主要服务区域。
- 每条航线展示预计出发时间、预计完成时间、线路总时长。
- 每条航线展示多个锚地节点。
- 每个锚地节点展示服务船舶、预计到锚时间、供给开始时间、供给时长。
- 需要体现线路优化后“一船多供”的效果。

示例航线：

1. A交通艇：小干岛码头 → 马峙锚地 → 秀山东锚地
2. B交通艇：小干岛码头 → 虾峙门南锚地 → 条帚门锚地
3. C交通艇：小干岛码头 → 绿华山南锚地 → 马迹山北锚地

每条航线卡片字段：

- 日期
- 交通艇名称
- 航线名称
- 航程距离
- 出发时间
- 预计完成时间
- 总耗时
- 节省空驶或合并供船提示
- 计划状态

锚地节点字段：

- 锚地名称
- 船舶名称或船舶编号
- 到锚时间
- 供给时间
- 作业时长
- 物资类型，伙食 / 物料 / 打包运输

视觉要求：

- 参考航班/车次卡片的展示方式。
- 左侧展示起点和终点，中间用时间轴或节点线表达线路。
- 右侧展示成本、节省时间或状态标签。
- 需要明显展示 A交通艇、B交通艇、C交通艇。
- 不做复杂地图，原型阶段使用卡片式路线图即可。

### 4.7 上新产品专区

首页气象信息和驳船调度下方需要有“上新产品”专区。

上新产品以 SKU 轮播形式展示，每个 SKU 卡片包含：

- 商品图片
- 商品名称
- 分类标签，伙食或物料
- 规格 / 单位
- 价格
- 供应商名称
- 新品标签

展示方式：

- 可横向轮播
- 可分 Tab：新伙食、新物料
- 不展示过多业务说明

### 4.8 优质供货商专区

首页需要有“优质供货商”专区。

展示方式：

- 使用供应商 Logo 卡片轮播
- 每个供应商一张卡片
- 不使用对标网站品牌名称
- 不出现“鼎恒 / 鼎衡”等字样

每张卡片字段：

- 供应商 Logo
- 供应商名称
- 主营品类
- 服务港口
- 响应速度
- 评分或履约能力

供应商名称统一使用虚拟名称，不使用真实公司名或对标站公司名。

供应商示例：

- A供货商
- B供货商
- C供货商
- D供货商
- E供货商

如果需要区分主营方向，可使用：

- A供货商：伙食
- B供货商：物料
- C供货商：打包运输
- D供货商：综合船供

### 4.9 热门产品区域

首页下方可以展示热门产品，呈电商商品流形式。

商品卡字段：

- 商品图片
- 商品名称
- 价格
- 单位
- 供应商
- 备货状态
- 加入购物车按钮

热门产品不要混入系统功能说明。

## 5. 集采导入界面需求

### 5.1 页面定位

集采导入界面面向公司采购用户，用于上传 Excel / CSV 采购清单，或通过搜索补充常用商品与备件。

页面参考用户提供的示意图。

### 5.2 页面结构

页面分左右两块。

左侧：上传采购清单

- 标题：上传采购清单，智能匹配商品与供应商
- 上传区域
- 支持 Excel / CSV
- 显示文件大小限制
- 下载模板按钮
- 上传清单按钮

右侧：搜索常用商品与备件

- 搜索框
- 搜索按钮
- 热门搜索词
- 常用分类宫格

### 5.3 常用分类宫格

集采导入页可展示常用分类宫格，便于用户不上传文件时快速检索。

宫格示例：

- 通用物料
- 油漆涂料
- 化学品
- 救生消防 / PPE
- 甲板机械
- 电气备件
- 润滑油
- 推进装置
- 货物装卸设备
- 消防救生设备
- 机舱设备
- 新造船物料
- 船员生活物资
- 全部分类

### 5.4 交互规则

- 用户上传清单后进入“采购清单匹配结果”页面。
- 用户通过搜索选择商品时，可加入当前集采清单。
- 上传清单后不直接发起报价。
- 系统先解析条目、匹配标准 SKU，再让用户选择价格策略。

## 6. 采购清单匹配结果界面需求

### 6.1 页面定位

该页面用于展示 Excel 集采导入后的匹配结果。用户在这里确认匹配结果、选择价格策略、勾选条目，并进行一键报价。

页面参考用户提供的“采购清单匹配结果”示意图，但业务逻辑需要调整为：

- 支持复选勾选
- 支持两种价格标准
- 主操作是一键报价
- 不是每一行单独发起报价

### 6.2 顶部流程步骤

顶部展示 5 步流程：

1. 上传清单
2. 解析条目
3. 匹配标准 SKU
4. 选择报价策略
5. 生成报价 / 订单

当前页面处于第 3 步到第 4 步。

### 6.3 清单概要

页面顶部展示上传文件信息：

- 文件名
- 上传时间
- 解析条目数
- 重新上传入口
- 清单设置
- 解析日志

### 6.4 匹配统计

展示匹配结果统计：

- 精确匹配数量
- 相似匹配数量
- 待人工确认数量
- 未匹配数量
- 总条目数

### 6.5 两种价格标准

页面需要提供价格策略切换。

#### 6.5.1 按供货商打包报价

以供应商维度生成方案。

适用场景：

- 船供集采
- 需要同一家供应商统一打包
- 希望减少运输、对账和交付复杂度

展示内容：

- 推荐主供应商
- 覆盖条数
- 缺少条数
- 可替代条数
- 预计商品总价
- 打包运输费
- 预计交期
- 缺少物料清单入口

该模式下，系统优先推荐同一家供应商覆盖最多的方案。

#### 6.5.2 按最低价组合报价

以单个 SKU 的最低价为准，从多个供应商组合出最低价格方案。

适用场景：

- 用户更关注最低采购价
- 可接受多个供应商供货

展示内容：

- 最低价总额
- 涉及供应商数量
- 预计节省金额
- 可能增加的打包运输成本
- 可能增加的对账复杂度

该模式下，系统需要提示用户：最低采购价不一定等于最低履约总成本。

### 6.6 表格结构

匹配结果表格字段：

- 复选框
- 序号
- 原始物料名称
- 请求规格 / 型号
- 分类
- 匹配结果
- 匹配度
- 标准 SKU / IMPA 编码
- 推荐供应商
- 当前价格策略下价格
- 可选品质
- 状态
- 操作

### 6.7 批量选择规则

表格支持：

- 全选
- 只选精确匹配
- 只选相似匹配
- 排除未匹配
- 排除待人工确认
- 手动逐行勾选

默认规则：

- 精确匹配默认勾选
- 相似匹配可默认勾选，但显示风险标签
- 待人工确认默认不勾选
- 未匹配默认不勾选

### 6.8 一键报价

主按钮为：

> 一键报价

一键报价作用：

- 根据用户勾选的条目
- 根据当前价格策略
- 生成一个报价方案

一键报价不是同时向多个供应商分散发送多个询价。

一键报价后可进入报价确认或报价单生成页面。

### 6.9 行内操作

每一行不以“发起询价”为主操作。

行内操作建议：

- 查看详情
- 确认匹配
- 替换 SKU
- 查看替代
- 移出报价

### 6.10 右侧信息区

右侧信息区包含：

- 分类分布
- 匹配质量概览
- 推荐供应商 TOP5
- 当前报价策略摘要
- 下一步建议

当前报价策略摘要随价格策略切换而变化。

### 6.11 关键业务规则

- 切换价格策略不会改变匹配结果，只改变推荐供应商和价格方案。
- 未匹配条目不能自动参与报价。
- 待人工确认条目需要确认后参与报价。
- 相似匹配条目可以参与报价，但必须显示风险标签。
- 用户可以复选勾选后再一键报价。
- 生成的是一个报价方案，不是多条分散询价。

## 7. 个人采购界面需求

### 7.1 页面定位

个人采购界面是普通电商商品清单页。用户可以搜索商品、筛选商品、查看热门产品、加入购物车。

该页面类似电商搜索结果页。

### 7.2 页面结构

顶部：

- 搜索框
- 搜索按钮
- 热门搜索词

左侧筛选：

- 分类
- 品牌
- 供应商
- 价格区间
- 有货状态
- 配送区域
- 商品类型，伙食 / 物料 / 服务

中间主体：

- 商品列表
- 商品卡片
- 排序栏
- 分页

排序方式：

- 综合
- 销量
- 新品
- 价格升序
- 价格降序

### 7.3 商品卡字段

商品卡展示：

- 商品图片
- 商品名称
- 规格 / 型号
- 单位
- 价格
- 供应商
- 备货时长
- 库存状态
- 加入购物车
- 查看详情

物料商品可展示：

- IMPA / MSG 编码
- 供应商编码

伙食商品可展示：

- 伙食分类
- 包装规格
- 保鲜 / 冷冻标签

### 7.4 热门产品

个人采购页下方或搜索结果中展示热门产品流。

热门产品应像电商页面一样连续展示商品，不展示业务流程。

### 7.5 打包费用规则

个人采购需要支持打包费用规则。

示例规则：

- 未满指定金额收取打包费
- 满指定金额免打包费
- 冷链、易碎、特殊包装商品可配置额外打包费

具体金额和规则后续配置。

## 8. 供应商与品牌内容要求

### 8.1 禁止内容

页面中不得出现：

- 鼎恒
- 鼎衡
- 对标站品牌
- 对标站真实供应商排行内容

### 8.2 供应商内容

原型中使用虚拟供应商，名称需要专业、可信。

供应商展示应重点体现：

- 主营品类
- 服务港口
- 响应速度
- 评分
- 是否支持打包运输
- 是否支持企业集采

## 9. 待确认问题

以下内容需要后续确认：

1. 首页 Banner 使用哪一张小干岛或港口图片。
2. 平台正式名称和 Logo。
3. 个人采购满额免打包费的金额规则。
4. 集采一键报价后进入“报价确认页”还是直接生成“报价单”。
5. 供应商维度报价时，是否允许一个主供应商 + 少量补充供应商。
6. 物料 IMPA / MSG 分类是否需要完整展示全部码段，还是只展示常用码段。
