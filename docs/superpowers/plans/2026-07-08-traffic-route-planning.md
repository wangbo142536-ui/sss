# 交通服务路线规划一期实现计划

## 目标

在交通服务下新增“路线规划”能力：基于已有交通服务订单创建路线，把同一天、同海域或同锚地附近的订单加入一条路线，形成拼船路线。实现一期人工规划闭环，不做真实地图算法。

## 范围

1. 后端新增路线规划表、路线停靠点表、路线事件表。
2. 后端提供路线列表、详情、新建路线、加入订单、调整顺序、移除订单、确认/开始/完成/废弃路线接口。
3. 前端新增菜单“路线规划”，展示筛选区、路线列表、地图占位区、右侧站点卡片、待规划订单区。
4. 复用现有交通服务订单数据，不新增付款、结算、真实地图、自动派船算法。

## 验证

1. 前端构建通过。
2. 后端构建通过。
3. 重启后端后，路线接口不返回 404。
4. 页面能进入路线规划菜单并加载真实接口或空态。
