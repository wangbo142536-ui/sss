# 船供平台一期页面原型清单与功能菜单结构

## 1. 文档目的

本文件用于把船供平台一期需求转化为可落地的产品页面结构。它重点回答三个问题：

- 系统一期需要哪些菜单和页面。
- 每个页面解决什么业务问题。
- 页面里需要展示哪些核心信息、支持哪些操作。

一期范围继续保持收敛：船代企业端和供应商协同端优先落地；船东端、监管直连、支付担保、实时定位作为后续能力预留。

## 2. 一期产品入口

### 2.1 船代企业端

船代企业端是一期主入口，面向船代管理员、业务员、现场操作员使用。核心目标是让船代围绕一张船供订单完成从需求录入到对账归档的全过程管理。

主菜单建议：

- 工作台
- 船供订单
- 询价报价
- 标准商品库
- 供应商池
- 备货验货
- 物流交付
- 单证归档
- 对账结算
- 统计看板
- 系统设置

### 2.2 供应商协同端

供应商协同端面向供应商管理员和供应商业务员使用。核心目标是让供应商完成报价、接单、备货、交付资料上传。

主菜单建议：

- 工作台
- 询价单
- 供货订单
- 商品映射
- 备货交付
- 对账记录
- 企业资料

### 2.3 平台运营端

平台运营端用于维护基础数据和平台级规则。一期可以轻量建设，不需要做复杂运营系统。

主菜单建议：

- 平台工作台
- 企业管理
- 供应商基础资料
- 标准商品库
- 类目与单位
- 单证模板
- 操作日志

## 3. 船代企业端页面清单

### 3.1 工作台

页面目标：让业务员一进入系统就知道今天要处理什么。

核心信息：

- 今日待询价订单数
- 待船东确认订单数
- 待供应商接单订单数
- 待验货订单数
- 待交付订单数
- 待对账订单数
- 异常订单提醒
- 即将到达补给时间的订单

核心操作：

- 新建船供订单
- 查看待办
- 进入异常订单
- 进入今日交付任务

### 3.2 船供订单列表

页面目标：作为船代业务的主入口，统一查询和跟进全部订单。

筛选条件：

- 订单编号
- 船名
- 航次
- 港口
- 补给时间
- 订单状态
- 业务员
- 供应商
- 是否加急
- 是否异常

列表字段：

- 订单编号
- 船名/航次
- 港口/泊位或锚位
- 补给时间
- 船东或船管公司
- 当前状态
- 负责业务员
- 供应商数量
- 费用总额
- 异常标记
- 更新时间

核心操作：

- 新建订单
- 查看详情
- 复制订单
- 取消订单
- 导出订单列表

### 3.3 船供订单详情

页面目标：围绕一张订单展示完整业务进度，是一期最核心页面。

页面结构：

- 基础信息区
- 补给清单区
- 询价报价区
- 船东确认区
- 备货验货区
- 物流交付区
- 单证归档区
- 对账结算区
- 操作记录区

核心操作：

- 编辑订单基础信息
- 导入补给清单
- 匹配标准商品
- 发起询价
- 汇总报价
- 登记船东确认
- 生成供应商订单
- 上传验货照片
- 登记物流节点
- 上传签收资料
- 生成对账单
- 导出归档包

### 3.4 新建船供订单

页面目标：快速创建一张可流转的船供订单。

表单字段：

- 船名
- 航次
- IMO/MMSI
- 港口
- 泊位或锚位
- 预计到港时间
- 预计离港时间
- 计划补给时间
- 补给地点
- 船东或船管公司
- 船方联系人
- 船代业务员
- 加急标记
- 备注
- 委托邮件或附件

核心操作：

- 保存草稿
- 提交并进入待询价
- 上传附件
- 复制历史订单信息

### 3.5 补给清单管理

页面目标：把船东原始清单转成可询价、可比价、可统计的结构化明细。

核心字段：

- 原始物资名称
- 平台标准商品
- 品类
- 规格
- 单位
- 数量
- 品牌要求
- 是否允许替代品
- 备注
- 匹配状态

核心操作：

- 批量导入清单
- 手工新增明细
- 匹配标准商品
- 新增待确认标准商品
- 调整品类
- 删除明细
- 导出清单

### 3.6 询价单列表

页面目标：集中管理已发起的询价任务。

筛选条件：

- 询价单号
- 关联订单
- 供应商
- 品类
- 询价状态
- 报价截止时间

核心操作：

- 查看询价详情
- 催报价
- 关闭询价
- 补充说明

### 3.7 发起询价

页面目标：选择供应商并把补给明细发送给供应商报价。

页面结构：

- 待询价物资明细
- 推荐供应商列表
- 本企业供应商池
- 报价截止时间
- 询价说明
- 附件

核心操作：

- 按整单询价
- 按品类询价
- 按明细询价
- 选择多个供应商
- 发送询价

### 3.8 报价对比与汇总

页面目标：帮助业务员比较供应商报价，并生成对外报价单。

核心信息：

- 供应商名称
- 报价状态
- 单价
- 总价
- 库存说明
- 最早交货时间
- 报价有效期
- 替代品说明
- 历史履约评分

核心操作：

- 选择中标供应商
- 调整报价明细
- 添加费用项
- 生成内部成本单
- 生成对外报价单
- 导出标准报价模板

### 3.9 船东确认登记

页面目标：在一期不做船东端的情况下，把船东确认结果留存在订单中。

字段：

- 确认状态
- 确认时间
- 确认人
- 确认方式
- 确认附件
- 备注

核心操作：

- 登记已确认
- 登记拒绝或需调整
- 上传确认邮件或附件
- 退回报价调整

### 3.10 标准商品库

页面目标：维护平台统一商品标准，支撑清单匹配、询价比价和统计分析。

筛选条件：

- 标准商品编号
- 商品名称
- 品类
- 规格
- 单位
- 品牌
- 启用状态
- 审核状态

列表字段：

- 标准商品编号
- 标准名称
- 品类
- 规格
- 单位
- 常用别名
- 关联供应商商品数
- 状态

核心操作：

- 新增标准商品
- 编辑标准商品
- 批量导入
- 启用/停用
- 维护别名
- 合并重复商品

### 3.11 供应商池

页面目标：每家船代企业维护自己的供应商资源。

筛选条件：

- 供应商名称
- 服务港口
- 主营品类
- 合作状态
- 评价等级

列表字段：

- 供应商名称
- 联系人
- 服务港口
- 主营品类
- 报价响应率
- 准时交付率
- 异常次数
- 合作状态

核心操作：

- 新增供应商
- 编辑供应商
- 停用供应商
- 查看历史订单
- 查看供应商商品
- 维护评价

### 3.12 供应商商品映射

页面目标：把供应商自己的商品名称和规格映射到平台标准商品。

核心字段：

- 供应商
- 供应商商品名称
- 供应商规格
- 供应商单位
- 对应标准商品
- 服务港口
- 可供状态

核心操作：

- 新增映射
- 批量导入
- 修改映射
- 标记缺货或停供
- 提交待确认标准商品

### 3.13 备货验货

页面目标：管理供应商备货和船代验货过程。

核心信息：

- 订单编号
- 供应商
- 备货状态
- 计划送货时间
- 实际送货时间
- 验货状态
- 异常情况

核心操作：

- 查看备货进度
- 上传验货照片
- 登记清点数量
- 登记异常
- 发起补货或换货

### 3.14 物流交付

页面目标：记录港区运输、驳船任务和上船交付节点。

核心信息：

- 接货点
- 交付点
- 车辆信息
- 驳船信息
- 司机或船员联系人
- 计划时间
- 实际时间
- 当前节点
- 异常说明

核心操作：

- 新建物流任务
- 更新物流节点
- 上传现场照片
- 登记运抵申报资料
- 登记交付完成

### 3.15 单证归档

页面目标：按订单统一管理全部资料和附件。

- 补给清单
- 供应商报价
- 对外报价单

- 申报资料
- 验货照片

- 运抵资料
- 签收单
- 报关单

- 发票或付款凭证

核心操作：

- 导出订单归档包

### 3.16 对账结算

页面目标：完成应收、应付、费用项、发票和付款状态记录。

- 添加费用项

- 登记付款
- 上传凭证

## 7. 核心操作路径

### 7.1 船代业务主路径

1. 船代新建订单。
2. 导入补给清单。
3. 系统辅助匹配标准商品。
4. 船代选择供应商并发起询价。
5. 供应商在线报价。
6. 船代进行报价对比。
7. 船代生成对外报价单。
8. 船代登记船东确认结果。
9. 系统生成供应商供货订单。
10. 供应商确认接单并备货。
11. 船代验货并上传照片。
12. 船代登记物流交付节点。
13. 船代上传签收和单证资料。
14. 船代生成对账单。
15. 订单归档完成。

### 7.2 供应商报价路径

1. 供应商收到询价提醒。
2. 供应商查看询价明细。
3. 供应商填写价格、库存、交货时间和替代品说明。
4. 供应商提交报价。
5. 中标后供应商确认接单。
6. 供应商上传备货资料。
7. 供应商反馈送货或交付情况。

## 9. 下一步建议

下一步建议进入原型设计阶段，先画 P0 页面低保真原型。优先画船代端的订单列表、订单详情、补给清单、报价对比、标准商品库、供应商池；再画供应商端的询价单详情和供货订单。
